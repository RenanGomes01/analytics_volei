# Especificação do Sistema de Scout de Vôlei
## Visão Geral do Projeto
Web app offline-first para scout de vôlei (beach-first 2x2, suporte a indoor 6x6) baseado no Circuito Brasileiro. Foco em rali, métricas detalhadas e UI manual ágil.
## Princípios (Modelo de 3 Camadas)
1. Oficial/Observado: Placar, ordem, eventos imutáveis.
2. Derivado: Eficiência, side-out%, distribuição.
3. Tracking/IA (Futuro): Visão computacional separada das estatísticas oficiais.
